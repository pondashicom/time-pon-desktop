# TIME-PON DESKTOP

Windows向け「透明・枠なし・常に最前面・クリック透過」のタイマーオーバーレイ（Control / Overlay の2ウインドウ構成）

- Overlay：透明・枠なし・最前面・クリック透過（表示専用）
- Control：設定・操作・カンペ送信（操作専用）

公式サイト： https://pondashi.com/timepon-desktop/

---

## これはどんなアプリ？

イベント現場・配信などで使う計時用タイマーです。  
**操作画面（Control）** と **表示画面（Overlay）** を分離しているため、2画面以上の環境で

- 片方：オペレータが Control を操作
- 片方：返しモニター / 配信合成向けに Overlay を表示

のように運用する用途を想定しています。

---

## 主な機能

### タイマー
- カウントダウン / カウントアップ
- 表示形式：`HH:MM:SS` / `残り M分 S秒`（表示形式の切替）
- 開始値（分）設定
- 第1警告 / 第2警告（時間・色・有効/無効）
- タイマー表示のON/OFF（Overlay側の表示を切替）
- 現在時刻表示のON/OFF

### Overlay（透明表示）
- 透明背景 / 枠なし / 常に最前面
- クリック透過（背面アプリの操作を邪魔しない）
- フォント / サイズ / 色の変更
- 表示先ディスプレイ選択（2画面運用向け）
- 表示位置をドラッグで調整（Control側から）

### カンペ
- Control の入力テキストを Overlay に表示
- カンペ点滅のON/OFF

## 動作環境

- Windows 10/11（想定）
- 2画面以上の運用を推奨（返しモニター/配信合成など）

---

## 使い方

1. 起動すると **Control** と **Overlay** が開きます
2. Control で以下を設定
   - モード（カウントダウン/アップ）
   - 表示形式
   - 開始値（分）
   - 警告（第1/第2：時間・色・有効/無効）
   - 表示位置 / フォント / サイズ / 色
3. `スタート` で開始
4. カンペ欄に入力 → `送信` で Overlay に反映（`クリア` で消去）

---

## 注意

- ディスプレイ構成や Windows の「表示倍率（スケーリング）」によって、Overlay の見え方や位置が変わります。  
  **本番前に必ず現場の実機でテスト**してください。
- Overlay はクリック透過のため、閉じ方が分からない場合は **Control 側の操作**で閉じる/非表示にしてください。

## 開発者向け（ソースから起動）

### セットアップ & 起動

```bash
npm install
npm start
```

### 主要ファイル

- `main.js`：ウインドウ生成 / 状態管理 / タイマー制御 / IPC
- `preload.js`：renderer への API 提供
- `overlay.html / overlay.js`：透明 Overlay 表示
- `control.html / control.js`：操作 UI
